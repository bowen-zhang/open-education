## Fuel System

**Main tank**
- 3 chambers
- Fuel filler
- Fuel vent
- Fuel drain
- Fuel quantity sensors
- Fuel temperature / low level sensors
- Fuel level switch (<17 gal)


![bg right:45% fit](images/fuel-system.png)

---

## Fuel System

**Auxilary tank**

- Fuel filler
- Fuel vent
- Fuel drain
- Fuel level switch (empty)
- Transfer pump (electrical)

Operation
- To main tank only
- Warmed up by return line
